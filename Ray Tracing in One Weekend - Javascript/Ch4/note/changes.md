| Step  | Old Camera (First Edition)                                       | New Camera (Current Edition)                                              | What Changed          | Why Changed                                                                    |
| ----- | ---------------------------------------------------------------- | ------------------------------------------------------------------------- | --------------------- | ------------------------------------------------------------------------------ |
| **1** | Define `origin`, `lower_left_corner`, `horizontal`, `vertical`   | Define `camera_center`, `viewport_u`, `viewport_v`, `viewport_upper_left` | Camera representation | More flexible camera geometry.                                                 |
| **2** | Pixel location computed using normalized coordinates `u` and `v` | Pixel location starts from `pixel00_loc`                                  | Coordinate system     | Uses actual pixel positions instead of percentages.                            |
| **3** | Compute `u = i / nx`, `v = j / ny` for every pixel               | Compute `pixel_delta_u` and `pixel_delta_v` once                          | Pixel traversal       | Move one pixel at a time with fixed vectors.                                   |
| **4** | Ray direction = `lower_left_corner + u*horizontal + v*vertical`  | Ray direction = `pixel00_loc + i*pixel_delta_u + j*pixel_delta_v`         | Ray generation        | Direct pixel indexing replaces percentage calculations.                        |
| **5** | Rays pass through viewport grid based on `u`,`v`                 | Rays pass through the **center** of each pixel                            | Sampling location     | More accurate and standard sampling.                                           |
| **6** | Anti-aliasing requires modifying `u` and `v`                     | Add random offset to `pixel_center` using `pixel_delta_u/v`               | Anti-aliasing         | Simpler implementation.                                                        |
| **7** | Camera movement requires updating multiple vectors manually      | Camera already stores viewport basis and pixel spacing                    | Camera transforms     | Easier camera movement and rotation.                                           |
| **8** | Minimal camera implementation                                    | Extensible camera framework                                               | Architecture          | Supports depth of field, anti-aliasing, and future features without redesign.  |
| **9** | Think in **percentages** (`u`, `v`)                              | Think in **pixel centers** (`pixel00 + delta`)                            | Core concept          | Shift from normalized coordinates to pixel-space computation.                  |
